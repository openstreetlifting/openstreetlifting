# Introduction

This book explains why OpenStreetlifting exists, and information to contribute to it.

OpenStreetlifting is an **open**, **collaborative** project building a **permanent**
and **traceable** archive of all Streetlifting data, **freely** accessible to
everyone.

Important concepts in this project:

- open: the data and the code are both open source.
- collaborative: do not hesitate to reach
  out if you want to help or want my help.
- permanent: the archive is meant to be downloaded and kept for as long as
  possible, as common knowledge.
- traceable: data that is displayed or exported keeps its original source wherever
  it can.
- freely: the project costs nothing to use and carries no advertising

I will refuse any advertising or partnership that would harm the project
.

## How to help

If you have results from a competition that is not in the archive yet, you can open a pull request on [Github](https://github.com/openstreetlifting/openstreetlifting), see: [Contributing Data](./CONTRIBUTING_DATA.md). You can also contact me, see: [contact page](https://openstreetlifting.org/contact)
